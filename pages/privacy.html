Privacy notes.

This site is designed as a static public guide with a browser-local builder. It helps you create a file. It does not need to collect the file.

What happens in the builder

Your form answers are stored in this browser's `localStorage` so the preview can keep working if you move around the page. The generated Markdown is created by JavaScript in the browser. Downloading creates a file on your device. Copying places the text on your clipboard.

What this site does not do

The site does not include a database, login, analytics package, contact form, server-side storage or GitHub write action. It does not publish your Markdown file. You control whether you copy, download, edit, share or delete it.

What not to type into public tools

Do not type passwords, private keys, bank details, private addresses, sensitive health details, private contact details, protected locations, private photos, unapproved names, cultural material requiring permission or anything you would not want accidentally shared.

Before using a file with AI

Read the generated file first. Remove anything sensitive. Label public, private, trusted-only and draft material. When a file affects other people, seek permission before sharing details about them.
