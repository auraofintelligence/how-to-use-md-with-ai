How to Use Markdown with AI

Markdown turns a messy thought into useful AI context: purpose, boundaries, sources, requests, examples and review notes in one readable file.

Start the guide Build a starter file

For ordinary people, community groups, local builders and civic projects that need better prompts without giving up control.

Private life stays private

Keep sensitive identity, care, health, home, family and personal context in files you control. Share only what has a reason and permission.

Public power leaves receipts

Public money, promises, claims, decisions, donations, lobbying, conflicts, corrections and procurement should leave a trail people can follow.

Why markdown works

Markdown is plain text with enough structure for people and AI agents to read the same document. It keeps context portable, inspectable and easy to revise.

1

Headings create structure

`#`, `##` and `###` show the AI what belongs together.

2

Frontmatter sets the scene

Small metadata blocks can name status, privacy, dates and review needs.

3

Requests stay clear

A file can separate context from the actual task you want AI to perform.

4

Sources build trust

Links, dates and notes help an agent check facts instead of guessing.

5

Review notes improve quality

Human checks, open questions and corrections keep the work honest.

Build it. See it. Use it.

Answer a few careful questions, then download a starter `.md` file you can keep, edit and feed into an AI chat or coding agent.

ai-context-starter.md
---
title: "Community Noticeboard Brief"
visibility: public_draft
status: needs_human_review
---

# Purpose
Help locals understand what is happening.

## Context
- What changed
- Who it affects
- What needs checking

## Request For AI
Draft a plain-English notice.

## Source Links
- council page
- venue update

## Review Notes
- Check dates
- Ask before publishing contact details
