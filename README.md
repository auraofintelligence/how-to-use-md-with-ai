A public static guide and browser-local builder explaining why people create `.md` files from forms before working with LLMs, GenAI tools and coding agents.

**Public guide:** <https://auraofintelligence.github.io/how-to-use-md-with-ai/>

The site covers:

- why Markdown helps people give AI better context
- how `profile.md`, `aura.md`, `public_noticeboard.md`, `AGENTS.md` and `SKILL.md` fit together
- how to separate private context from public records
- why public money, promises, claims, decisions and corrections should leave receipts
- how to generate a local `ai-context-starter.md` file in the browser

## Local use

Open `index.html` in a browser. No build step is required.

## Privacy

The builder uses browser-local JavaScript and `localStorage`. It does not send form answers to a server. Visitors still need to inspect any generated file before sharing it with AI tools or other people.
